# ATO curation summary

Open `ato_summary.ipynb` to see the executed code and results; `ato_summary.html` is a Python-free
visual version. Run `python external_ato/build_summary.py` from the group repo root to regenerate
and re-execute it from the current results. Install `external_ato/requirements.txt` first; the
current Python environment is used as a temporary notebook kernel, and the global kernel is not modified.
