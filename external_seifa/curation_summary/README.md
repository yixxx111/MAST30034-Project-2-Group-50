# SEIFA results notebook

Open `seifa_summary.ipynb` for the executed results. The saved outputs come from the official ABS Postal Area SEIFA 2021 workbook and the local consumer postcode coverage audit.

The cleaning implementation is in `external_seifa/src/curation.py`. The notebook reads the saved files under `external_seifa/results/`; it does not contain a second, conflicting cleaning implementation.
